# Hatzolah Air Website Starter

Public-site starter for Hatzolah Air.

### Pages
- `index.html` — homepage
- `request-iflght.html` — link/bridge to the existing secure CRM intake form
- `donate.html` — integrated donation page

### Preview
Open `index.html`, or run:

```bash
python -m http.server 8080
```

### Integration links
Edit `assets/site.js` when the CRM moves from `app.adler-md.com` to `app.hatzolahair.org.il`.

See `CLAUDE.md` for the full handoff and next-step instructions.
